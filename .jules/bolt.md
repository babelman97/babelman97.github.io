## 2025-05-22 - Hybrid Unique Random Sampling Bottleneck
**Learning:** In random number generation (specifically picking unique numbers), a pure Set-based rejection sampling approach suffers from the "Coupon Collector's Problem". As the number of requested items (count) approaches the total range size, the probability of picking a new unique number decreases exponentially, causing O(N*log(N/(N-K))) complexity which hangs the main thread for large ranges (e.g., 1M numbers).
**Action:** Implement a hybrid strategy: Use rejection sampling for low density (count < 50% of range). For high density (count > 50%), use "selection by exclusion" (pick items to exclude) followed by a Fisher-Yates shuffle to preserve random output order. Always cap the total range size (e.g., < 10M) to prevent memory exhaustion from array allocations.
